# Проект e_commerce_project

## Описание:

Проект включает в себя классы:

1. Product со свойствами:

- название (name),
- описание (description),
- цена (price),
- количество в наличии (quantity)

2. Category со свойствами:

- название (name),
- описание (description),
- список товаров категории (products)
- количество категорий
- количество товаров

3. Smartphone(наследуется от Product) со свойствами:

- имя
- описание
- цена
- количество
- производительность
- модель
- память
- цвет

4. LawnGrass(наследуется от Product) со свойствами:

- имя
- описание
- цена
- количество
- страна производства
- время прорастания
- цвет

## Тестирование:

Проект покрыт тестами Pytest
Для их запуска выполните команду:

```
pytest --cov
```
