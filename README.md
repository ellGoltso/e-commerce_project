# Проект e_commerce_project

## Описание:

Проект включает в себя классы:

1. Product(наследуется от абстрактного класса BaseProduct) со свойствами:

- название (name),
- описание (description),
- цена (price),
- количество в наличии (quantity)

2. Category со свойствами:

- название (name),
- описание (description),
- список товаров категории (products)
- количество категорий
- количество товаров

3. Smartphone(наследуется от Product) со свойствами:

- имя
- описание
- цена
- количество
- производительность
- модель
- память
- цвет

4. LawnGrass(наследуется от Product) со свойствами:

- имя
- описание
- цена
- количество
- страна производства
- время прорастания
- цвет

5. PrintMixin - класс-миксин(при работе метода "init", печатать в консоль информацию о том, от какого класса и с какими параметрами был создан объект)

6. BaseProduct - абстрактный базовый родительский класс для продуктов
## Тестирование:

Проект покрыт тестами Pytest
Для их запуска выполните команду:

```
pytest --cov
```
